# C2 — бесконечная последовательность простых чисел

Простые числа вычисляются ленивым решетом Эратосфена без заданной верхней границы.

```clojure
(take 10 primes)
;; (2N 3N 5N 7N 11N 13N 17N 19N 23N 29N)
```

В таблице хранятся составные числа и шаги вычёркивания их кратных.
Если очередное число отмечено, `mark-next` переносит отметку дальше.
Если отметки нет, `sieve` выдаёт простое число и отмечает его квадрат.
Занятые места пропускаются: они уже отмечены другой цепочкой.
`lazy-seq` откладывает поиск до запроса следующего элемента.

`primes` — общая последовательность, `prime-seq` создаёт новую.
Суффикс N в выводе обозначает целые числа произвольной точности.

Запуск из папки `labs/C2` с установленным Clojure CLI:

```powershell
clojure -M:demo
clojure -M:test
```

Демонстрация печатает первые 25 простых. Тесты проверяют известные значения,
совпадение с перебором делителей, квадраты простых, пересечения цепочек,
ленивость и повторное чтение последовательности.
