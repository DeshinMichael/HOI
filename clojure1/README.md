# C1 — строки без одинаковых соседних символов

Функция `strings-without-repeats` возвращает все строки длины N из заданного
алфавита, в которых соседние символы различаются. Порядок результата не важен.

```clojure
(strings-without-repeats '("a" "b" "c") 2)
;; ("ac" "ab" "bc" "ba" "cb" "ca")
```

Решение начинается с одной пустой строки. `extend-string` добавляет к строке
каждый допустимый символ, `extend-all` собирает продолжения всех строк.
Через `reduce` расширение повторяется N раз. Используются `map`, `remove`
и `cons`, без рекурсии, генераторов и `flatten`.

Вход: алфавит из односимвольных строк без повторений и целое N >= 0.
При N = 0 результат содержит одну пустую строку.

Запуск из папки `labs/C1` с установленным Clojure CLI:

```powershell
clojure -M:demo
clojure -M:test
```

Тесты проверяют пример, пустой алфавит, длину и количество слов,
отсутствие одинаковых соседей и повторений в результате.
